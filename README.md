# Fundamentos de desarrollo web con HTML y CSS

## Resumen del curso

Curso introductorio para estudiantes de secundaria sin experiencia en programación.
La práctica consiste en crear **Sazón Peruana**, un recetario escolar con dos
recetas completas y un ejercicio para agregar otra. El ejemplo utiliza
etiquetas HTML y estilos básicos de color, letra y espaciado.

[Código fuente en GitHub](https://github.com/Market-Labs/social-responsability)

| Aspecto | Descripción |
| --- | --- |
| Público | Estudiantes de secundaria de 12 a 17 años. |
| Experiencia previa | No se requiere experiencia en programación. |
| Duración planificada | 60 minutos. |
| Modalidad | Seis lecciones con demostraciones y pausas para practicar. |
| Lenguajes | HTML5 y CSS3. |
| Herramientas | Navegador, editor gratuito en línea, GitHub y YouTube. |
| Resultado | Recetario con dos recetas completas y una práctica guiada. |

## Qué aprenderás

- Reconocer la función de HTML y CSS en una página web.
- Usar etiquetas, elementos y atributos de HTML.
- Crear encabezados, párrafos, listas, imágenes y enlaces internos.
- Aplicar selectores y propiedades de color, fuente, espacio y borde.
- Adaptar una página a pantallas pequeñas.
- Revisar las rutas de las imágenes y el nombre de la hoja de estilos.

## Cómo empezar sin instalar herramientas

1. Abre un editor gratuito en línea desde tu navegador.
2. Crea los archivos «index.html» y «styles.css».
3. Copia el HTML y el CSS del recetario en los archivos correspondientes
   del editor. [index.html](completed-examples/index.html) ·
   [styles.css](completed-examples/styles.css)
4. Comprueba que el enlace en el HTML apunte al archivo «styles.css».
5. Usa la vista previa para observar cada cambio.
6. Practica cambiando el título, una descripción o un color y observa el resultado.

Para probar el ejemplo en tu navegador, abre el archivo de la carpeta
«completed-examples». Conserva «starter-files» junto a esa carpeta
para que se carguen las fotos. [Abrir index.html](completed-examples/index.html)

Si el editor solo acepta HTML y CSS, reemplaza el prefijo «../starter-files/»
de cada ruta de imagen por la dirección de la carpeta en GitHub y conserva
el nombre del archivo.

~~~text
https://raw.githubusercontent.com/Market-Labs/social-responsability/main/starter-files/
~~~

El recetario funciona con HTML y CSS. Para el curso, realiza las
demostraciones en el editor en línea.

## Proyecto de práctica

1. **Presentación** con el nombre del recetario y enlaces de texto.
2. **Recetas** de lomo saltado y causa limeña con fotos, ingredientes y pasos.
3. **Ahora te toca a ti** con dos opciones para practicar: ají de gallina y arroz chaufa.
4. **Pie de página** con los créditos de las fotos del ejemplo.

El recetario tiene un archivo HTML y una hoja CSS en «completed-examples».
«starter-files» contiene cuatro fotos JPG. Dos aparecen en el recetario y
las de ají de gallina y arroz chaufa quedan como recursos para la práctica.
La carpeta «scripts» está reservada para los guiones.
